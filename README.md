# PharmaMarketing — Календарь маркетинговых кампаний

Веб-приложение для операционного планирования маркетинговых активностей фармацевтической компании с AI-поддержкой.

## Описание

PharmaMarketing решает задачу разрозненного планирования между маркетингом и полевыми командами. Система объединяет календарь сезонных пиков спроса, план кампаний, матрицу SKU по регионам и AI-рекомендации в единый операционный инструмент.

Контекст: фармацевтическая компания с собственным производством и полевыми командами. Продуктовые линейки охватывают сезонные категории — ОРВИ, аллергия, кардио, ЖКТ, летний сезон.

### Функциональность

- **Календарь сезонов** — тепловая карта пиков спроса по месяцам и регионам с привязкой активных кампаний
- **Управление кампаниями** — полный жизненный цикл: Планирование → Активна → Завершена, с бюджетом, каналами, регионами и целями
- **Матрица SKU × Регион** — таблица присутствия препаратов по регионам с индикацией активных кампаний и остатков на складе
- **Чек-лист запуска** — задачи по категориям (Материалы, Обучение, Логистика, Согласования) с отслеживанием выполнения
- **План/Факт метрики** — редактируемые показатели с визуальным прогрессом
- **AI-анализ рисков** — выявление рисков кампании с митигацией и оценкой окна запуска
- **AI-рекомендации** — оптимизация бюджета, каналов, сроков + бриф для команды
- **AI-конфликты** — выявление пересечений кампаний по времени, регионам и каналам
- **AI-чек-лист** — генерация задач запуска на основе параметров кампании
- **Аналитика** — бюджет по месяцам и каналам, просроченные задачи, распределение по сезонам

### Стек

- **Next.js 14** App Router (TypeScript) — fullstack
- **In-memory хранилище** — синтетические данные, без внешней БД
- **OpenRouter API** → Claude Sonnet — AI через fetch
- **Vercel** — деплой
- **Tailwind CSS** + кастомные CSS-переменные

## Принятые решения

**In-memory вместо БД** — по условию задания запрещены внешние хранилища. Все данные синтетические, хранятся в памяти процесса. При старте инициализируются 4 демо-кампании и 8 SKU.

**Next.js fullstack** — фронтенд и API в одном проекте. На Vercel API Routes деплоятся как serverless functions автоматически.

**OpenRouter вместо прямого Anthropic SDK** — предоставленный ключ работает через OpenRouter. Интеграция через нативный `fetch` без дополнительных зависимостей.

**Краткие промпты** — для предотвращения обрезания JSON-ответов промпты явно ограничивают количество пунктов. System prompt требует отвечать только JSON без markdown.

**Ключ только через переменную окружения** — `process.env.OPENROUTER_API_KEY` читается внутри функции при каждом вызове. `.env.local` добавлен в `.gitignore` и никогда не попадает в репозиторий.

## Синтетические данные

**4 кампании:**
- Осенний антигрипп 2025 (ОРВИ, Завершена, 8.5M руб.)
- Весна без аллергии 2026 (Аллергия, Активна, 5.2M руб.)
- КардиоЗима 2025-2026 (Кардио, Активна, 12M руб.)
- Летний ЖКТ 2026 (Летний, Планирование, 3.8M руб.)

**8 SKU** — препараты категорий ОРВИ, Аллергия, Кардио, Гастро, Летний с ценами и остатками

**5 сезонных пиков** — с указанием месяцев пика и регионов присутствия

## AI-функционал

| action | Описание |
|---|---|
| `analyze_risks` | Риски кампании: severity, mitigation, окно запуска |
| `recommend` | Рекомендации по оптимизации + бриф для команды |
| `detect_conflicts` | Пересечения между активными кампаниями + советы |
| `generate_checklist` | Чек-лист запуска по каналам и дате старта |

## Инструкция по запуску

```bash
git clone https://github.com/admukhortikova/pharma-marketing-calendar.git
cd pharma-marketing-calendar
npm install
```

Создать файл `.env.local` в корне проекта:
```
OPENROUTER_API_KEY=ваш_ключ_от_openrouter
```

```bash
npm run dev
# Открыть http://localhost:3000
```
