# PharmaMarketing — Календарь маркетинговых кампаний

Веб-приложение для операционного планирования маркетинговых активностей фармацевтической компании с AI-поддержкой на базе Claude (OpenRouter).

## Демо

🔗 **[pharma-marketing-calendar.vercel.app](https://pharma-marketing-calendar.vercel.app)**

📁 **[github.com/admukhortikova/pharma-marketing-calendar](https://github.com/admukhortikova/pharma-marketing-calendar)**

---

## Описание

PharmaMarketing решает задачу разрозненного планирования между маркетингом и полевыми командами. Система объединяет календарь сезонных пиков спроса, план кампаний, матрицу SKU по регионам и AI-рекомендации в единый операционный инструмент.

Контекст: фармацевтическая компания с собственным производством и полевыми командами. Продуктовые линейки охватывают сезонные категории — ОРВИ, аллергия, кардио, ЖКТ, летний сезон.

## Функциональность

### Управление кампаниями
- Полный жизненный цикл: Планирование → Активна → Приостановлена → Завершена
- Редактирование целей, бюджета (общий + потраченное), каналов и регионов прямо в карточке
- Выбор регионов из полного списка субъектов РФ (~80 регионов) с поиском
- Мультиканальное продвижение: Аптека, Диджитал, Мерч, Полевые визиты, Конференции

### Календарь сезонов
- Тепловая карта пиков спроса по месяцам для 5 сезонных категорий
- Привязка к регионам с цветовой индикацией
- Временная шкала активных кампаний поверх сезонной карты
- Фильтрация по сезону кликом на легенду

### Матрица SKU
- Таблица SKU × Регион с индикацией присутствия и активных кампаний
- Режим SKU × Кампании — список активных кампаний для каждого препарата
- Индикаторы остатков на складе (Высокий / Средний / Низкий)
- Фильтрация по сезонной категории

### Чек-лист запуска
- AI-генерация задач на основе каналов, регионов и даты старта
- Ручное добавление задач с категорией, сроком и ответственным
- Отметка выполнения, удаление задач
- Индикация просроченных задач с подсветкой

### План/Факт метрики
- Добавление метрик при создании и редактировании кампании
- Визуальный прогресс план/факт с цветовой индикацией
- Обновление фактических значений в любой момент

### AI-анализ (вкладка в каждой кампании)
- **Риск-лист** — конкуренция за внимание, перегруз торговых точек, сезонные риски с митигацией
- **Окно запуска** — оптимальный тайминг на основе сезонных паттернов
- **Конфликты ресурсов** — предупреждение о пересечениях с другими активностями
- **Рекомендации** — оптимизация бюджета, каналов, сроков, регионов
- **Бриф для каналов** — готовые формулировки для внутренней коммуникации

### AI на дашборде
- Автоматическое выявление пересечений между активными кампаниями
- Конфликты по времени, регионам и каналам
- Советы по оптимизации расписания активностей

### Экспорт в PDF-презентацию
- 4 слайда: титульный, бюджет/KPI, чек-лист, сводка
- Формат A4 альбомный, оптимизирован для печати
- Кнопка «↓ Экспорт PDF» на странице каждой кампании

### Аналитика
- Бюджет по месяцам запуска и каналам
- Распределение кампаний по сезонам
- Просроченные задачи чек-листа
- Общее освоение бюджета

### Роли пользователей
Переключатель роли в шапке каждой кампании:
- **Категорийный менеджер OTC** — полный доступ, редактирование
- **Региональный менеджер** — полный доступ, редактирование
- **Финансы (просмотр)** — только просмотр без редактирования

## Архитектура

```
pharma-marketing/
├── app/
│   ├── page.tsx                        # Дашборд: KPI, AI-конфликты, таблица кампаний
│   ├── layout.tsx                      # Root layout
│   ├── globals.css                     # Дизайн-система (dark theme, CSS-переменные)
│   ├── api/
│   │   ├── campaigns/route.ts          # GET список, POST создание
│   │   ├── campaigns/[id]/route.ts     # GET детали, PATCH обновление
│   │   ├── ai/route.ts                 # AI: 4 действия через OpenRouter
│   │   └── export/route.ts             # Статистика, тренды, просрочки
│   ├── calendar/page.tsx               # Тепловая карта сезонов
│   ├── campaigns/
│   │   ├── page.tsx                    # Реестр кампаний с фильтрами
│   │   ├── new/page.tsx                # Форма создания + AI-чек-лист
│   │   └── [id]/
│   │       ├── page.tsx                # Детали: 4 вкладки (Обзор, Чек-лист, План/Факт, AI)
│   │       └── export/page.tsx         # PDF-презентация для печати
│   ├── matrix/page.tsx                 # Матрица SKU × Регион
│   └── reports/page.tsx                # Аналитика и отчёты
├── components/
│   ├── Sidebar.tsx                     # Боковая навигация
│   └── RegionSelector.tsx              # Выбор регионов РФ с поиском
└── lib/
    └── db.ts                           # In-memory хранилище + синтетические данные
```

### Стек

- **Next.js 14** App Router (TypeScript) — fullstack в одном проекте
- **In-memory хранилище** — синтетические данные, без внешней БД
- **OpenRouter API** → Claude Sonnet (`anthropic/claude-sonnet-4-5`) — AI-интеграция через fetch
- **Vercel** — деплой с автоматическим CI/CD при пуше в GitHub
- **Tailwind CSS** + кастомные CSS-переменные (dark theme)

## Принятые решения

**In-memory вместо БД** — по условию задания запрещены внешние хранилища. Все данные синтетические. При старте инициализируются 4 демо-кампании и 8 SKU через `globalThis` для персистентности в рамках процесса.

**Next.js fullstack** — фронтенд и API в одном проекте. На Vercel API Routes деплоятся как serverless functions автоматически без дополнительной конфигурации.

**OpenRouter вместо прямого Anthropic SDK** — по условию задания предоставлен ключ OpenRouter. Интеграция через нативный `fetch` без SDK-зависимостей. Ключ хранится исключительно в переменных окружения Vercel, никогда не попадает в репозиторий.

**Короткие промпты с ограничениями** — для предотвращения обрезания JSON-ответов промпты ограничивают количество пунктов и длину полей. System prompt требует отвечать только JSON без markdown.

**RegionSelector** — отдельный компонент с полным списком ~80 субъектов РФ, поиском и мультивыбором. Используется и при создании, и при редактировании кампании.

## AI-функционал

| action | Где | Описание |
|---|---|---|
| `analyze_risks` | Кампания → AI-анализ | Риск-лист, окно запуска, конфликты ресурсов |
| `recommend` | Кампания → AI-анализ | Рекомендации по оптимизации + бриф для каналов |
| `detect_conflicts` | Дашборд | Пересечения между активными кампаниями |
| `generate_checklist` | Создание кампании | Чек-лист запуска по каналам и дате |

## Инструкция по запуску

```bash
git clone https://github.com/admukhortikova/pharma-marketing-calendar.git
cd pharma-marketing-calendar
npm install
```

Создать файл `.env.local` в корне:
```
OPENROUTER_API_KEY=ваш_ключ_от_openrouter
```

```bash
npm run dev
# Открыть http://localhost:3000
```
